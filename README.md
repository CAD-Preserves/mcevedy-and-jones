# mcevedy-and-jones

Root directory for McEvedy and Jones. Manual digitizations which were done previously are placed in the root directory.
- `/output/mcevedy_data.json`: Population figures per year.
- `mcevedy_subdivisions.png`: The areal masks McEvedy used. Standardized to HYDE land area (4320x2160, WGS84 Equirectangular, 5-arcmin).

Using CV-aided graph and corpus extraction, we created annualised time-series beyond the figures highlighted by McEvedy and Jones. Since the graphs and texts displayed more granular figures and population changes beyond the explicitly labelled numbers, we thought it worth extracting.

This work was previously attempted manually in some publicly uploaded copies of McEvedy and Jones, but have not been made available in JSON form to our knowledge. Honourable mention to Moscow State University, [who tried doing it by pencil](https://dmo.econ.msu.ru/Teaching/Histpop/Reading/Atlas%20of%20World%20Pop%20History%20McEvedy&Jones.pdf) and uploaded their annotations of the book online. It was a truly charming attempt.
